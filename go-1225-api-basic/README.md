> Creating api with go 1.22.5 latest stable version release with powerfull native net/http
reff: https://go.dev/doc/go1.22

**Note- make sure that go 1.22.5 is installed on your work system**

```bash
# create a empty folder & navigate to the folder dir 
go mod init github.com/yourUsername/repo/yourProjectFolderName

# start the server
go run main.go api.go
```
